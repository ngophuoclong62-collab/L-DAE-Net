# L-DAE Net: A Lightweight Target-Adaptive Framework for 3D Medical Image Segmentation

This repository contains the official PyTorch implementation of the paper:
**"A lightweight target-adaptive framework for 3D medical image segmentation"**

## 📢 Status

In accordance with open-science principles, the complete source code, custom network definitions (L-DAE Net and L-DAE Net-S), GT-CAMS search algorithms, and fully trained model weights will be comprehensively uploaded and made publicly available here immediately upon the publication of the paper.

## 🎯 Overview
- **Data-End:** Target-structure collaborative adaptive slice screening.
- **Model-End:** Lightweight Dual-Axis Attention Enhancement Network (L-DAE Net).
- **Search Strategy:** Geometric-Topological Coupled Adaptive Architecture Search (GT-CAMS).
